棒木幕府・Discord自動伝令システム

🔔 3人の予定が合った時だけDiscordへ自動通知！

1人・2人が入力した段階や「×」の日は通知せず、3人全員が「◯」または「△」で揃った瞬間だけ普段のDiscordチャンネルへ自動で集合伝令を飛ばします。

スパムゼロの厳密判定

3人全員が「◯（全員◯）」または「◯＋△（3人集合可）」になった日のみ自動送信します。

遊ぶゲーム＆時間も通知

その日に設定したゲームタイトル（アイコン付）や集合時間、3人の内訳をカード形式で綺麗に通知します。

1人が設定すれば3人全員に適用

Webhook URLはクラウド同期されるため、代表者1人が設定するだけで誰が3人目の「◯」を押しても通知が飛びます。

完全無料・今すぐiPhoneアプリ化 (PWA)

3人のiPhoneのホーム画面にアイコンを追加する方法

Appleの年間登録料（約15,000円）を払わなくても、このサイトをiPhoneの「ホーム画面に追加」するだけで、アドレスバーが消えてフルスクリーンのネイティブアプリとして動きます！

  1. 1 URLをLINEやDiscordで友達2人に送る
  2. 2 Safariの下部にある「共有ボタン（四角から上矢印）」をタップ
  3. 3 「ホーム画面に追加」をタップすると、専用アイコンでいつでもワンタップ起動！
どこでどうやって動かす？（無料公開＆3人同期ガイド）

最短3分でネット公開して3人で共有する手順

EXTERNAL HOSTING SETUP

外部サイト公開時の3人リアルタイム同期ガイド

このプレビュー画面内ではすでに自動でクラウド同期が稼働していますが、自分で GitHub Pages / Netlify / Vercel などに index.html をアップロードして使う場合は、無料のFirebaseプロジェクトを1つ繋ぐだけで3人同期が動きます。

  1. Firebase Console（無料）で新規プロジェクトを作成
  2. 「Authentication」➔「Sign-in method」で「匿名（Anonymous）」を有効化
  3. 「Firestore Database」を作成し、プロジェクト設定から firebaseConfig（JSON）をコピーして下の欄に貼り付ければ完了です！
